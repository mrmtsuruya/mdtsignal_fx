## Signal Definition

A signal is a structured message that communicates a trading intention (BUY, SELL, CLOSE) for a specific instrument, generated by a strategy and forwarded through the platform pipeline.

## Signal Lifecycle

1. **Generated** — Pine Script fires alert
2. **Received** — Hermes webhook receiver captures payload
3. **Validated** — Schema and rule validation
4. **Enriched** — AI confidence scoring applied
5. **Dispatched** — Forwarded to MT5 bridge
6. **Executed** — Order placed on broker
7. **Archived** — Stored in database

## Signal Types

| Type | Description |
|---|---|
| `ENTRY_LONG` | Open a long position |
| `ENTRY_SHORT` | Open a short position |
| `CLOSE_LONG` | Close an existing long position |
| `CLOSE_SHORT` | Close an existing short position |
| `MODIFY` | Modify stop-loss or take-profit |
